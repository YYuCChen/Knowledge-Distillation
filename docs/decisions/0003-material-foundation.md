# 决策0003：素材基座——洗净、切配，不调味

> 2026-09-29 更新：存放目录、实体登记与客观关系边、"仅凭 vault 重建数据库"等条目已被[决策0004](0004-phase2-alignment.md)调整；raw 的现行格式见 [raw 接口规格](../engineering/raw-interface.md)。洗净与切配的边界继续有效。


状态：已定（2026-09-29 用户确认）。依据讨论见[二期讨论进展](../roadmap/phase2-discussion.md)。执行时遵守 [AGENTS.md 最高工作原则](../../AGENTS.md)。本决策覆盖[决策0002](0002-phase2-knowledge-backbone.md)中与素材存放相关的部分；0002 中关于锚点、关系、导览、个人层的设计降级为下游（"调味"）方向，暂不实施。

## 背景

讨论中反复尝试预先设计个人知识库的信息结构，都没有令人满意的结果。调研显示，"结构是挣得的，不是设计出来的"。因此先夯实唯一能想清楚、而且不可逆的部分：素材基座。信息结构留待在真实使用中逐步长出来。

个人知识库的范围是"关于我的一切"：所见（外部材料）、所思、所历、所为。基座对所有素材一视同仁：**素材进来，先不把"我"扯进来，先把素材本身拆清、理顺。** "我"只在素材本身就是我说的、我做的时，以作者身份出现。

## 决定

### 1. 边界：只做洗净和切配

- **洗净**：把食材弄干净，但不改变它是什么。
- **切配**：切成标准的块，认清食材是什么。
- **调味**（不属于基座，本阶段不做）：概览、观点与证据的提炼、概念、立场与逻辑关系、新知、导览、用户反应和画像。一期的蒸馏结果属于调味，予以保留，但不作为基座。

### 2. 洗净

1. **取全**：取得完整的原件（全文、转写、图片文字、原话），记录出处和取得方式（渠道、工具、模型、版本）。
2. **去杂**：去掉非内容部分（平台模板、广告、分享文案）。只删不改，删除的部分可以追溯。口语中的语气词、改口属于内容，予以保留。
3. **纠错**：识别错误走现有的疑点核对流程；订正作为新版本保存，保留原始识别结果。
4. **规整**：统一为 Markdown 和 UTF-8；对话按发言人分开；音视频附时间码。
5. **定身份、定时间**：作者或发言者（本人或第三方）；`产生于`（内容产生的时间）；`收录于`（进入库的时间）。
6. **去重**：同一素材重复投递时，保持同一身份。

### 3. 切配

1. **切成片段**：以段落为最小单位（音视频按发言轮次或时间段，图文按图片），不切到句子，以免断章取义。每个片段有稳定编号，可以被精确引用。
2. **标出实体**：只标客观存在、叫得出名字的东西：人、组织、作品、产品、地点、时间点、具名事件。能对应到 Wikidata 的就记下其编号。概念（如"注意力""事后解释"）不在基座中标注。
3. **记下客观关系**：只记事实上存在、可以核实的关系。

### 4. 基座的本体（图模型）

节点：

| 类型 | 说明 | 身份 |
|---|---|---|
| 素材 | 一份完整的输入 | 稳定编号，与内容无关，永不改变 |
| 片段 | 素材内的一段 | 素材编号 + 序号；切好后不再改动 |
| 实体 | 客观存在的具名对象 | 本地稳定编号；如有 Wikidata 编号则一并记录 |

边：

| 边 | 从 → 到 |
|---|---|
| 含有 | 素材 → 片段 |
| 提及 | 片段 → 实体 |
| 作者 | 素材 → 实体（人或组织） |
| 发言者 | 片段 → 实体（人） |
| 同系列 | 素材 ↔ 素材（例如同一合集、同一对话） |
| 引用 / 转发 | 素材 → 素材或外部链接 |
| 时间相邻 | 素材 ↔ 素材（收录时间窗内相邻，附时间差） |

规则：
- 实体识别和实体合并都可能出错：高置信时自动处理，否则标为待确认。合并、拆分作为事件记录，可以撤销。
- 如果需要重新切分，则产生新版本，旧版本保留；新旧片段的对应关系属于可再生数据。
- 基座里不出现任何主观判断的边。

### 5. 存放

- **文件是正本**：仅凭 vault 就能完整重建数据库；数据库只是索引和加速。
- 每份素材一个文件，只按时间存放：`素材/YYYY/MM/<编号>-<标题>.md`。
  - frontmatter 为信封：编号、类型、作者、渠道、出处、产生于、收录于、取得方式、去杂记录、订正记录、实体提及、客观关系。
  - 正文为规整后的原件，每个片段带块编号（`^s1`、`^s2`……）。
- 媒体放在 `附件/`。
- `.kd/` 位于 vault 内，分两部分：
  - `.kd/registry/`：实体登记表等正本数据，文本格式，随 vault 保存；
  - `.kd/index/`：可以从正本重建的索引和图。
- **原始媒体默认保留**，不做任何删除。删除属于不可逆操作，必须由用户按类别逐一裁决。
- 除时间以外，暂不设计任何信息结构。

### 6. 与现有内容的关系

- 一期的 56 篇来源笔记所含原文，按本决策重新洗净、切配，进入 `素材/`。原笔记保留不动，作为"调味"产物，链接到对应的素材。
- 飞书随手记需求中"每天一个文件"的写法，改为按本决策"每份素材一个文件"；该需求中的其他不可逆要求继续有效。

## 可逆性

- **不可逆，已定**：原件不改；片段一旦切好不再改动；编号与内容无关；文件是正本；媒体默认不删除；本人与第三方的身份边界。
- **可逆，放手迭代**：去杂规则、实体类型的细分、Wikidata 的匹配方法、文件命名细节、索引的实现方式。
