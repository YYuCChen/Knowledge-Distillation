## Agent 建议及研究假设

这些观点用于继续讨论，不能被写成用户已经选择的架构。

- “目的型专题”“一次应用”是候选稳定对象。动态 Topic 与持续研究对象可能职责不同，是否增加实体、数据库字段或页面仍需决定。
- 应用时理解用户现场、适用前提、反例和信息缺口；先确认适用性，再交付可检查的成果。
- “我正在想的一件事 / 我正在做的一件事”是可能入口；认知知识可帮助察觉问题、提供解释、改善判断、建立联系，不一定生成行动清单。
- 只有反复使用、相对稳定、经过验证的流程才值得固化成独立 Skill，不默认一篇内容一个 Skill。
- 研究提出先验证应用包是否增加任务质量，再用少量应用入口验证使用价值；这不是已批准的二期路线。

完整论证与不同方案的代价见[四方向讨论](../history/2026-09-project-memory/four-directions-discussion.md)、[对话记录](../history/2026-09-project-memory/future-discussion.md)、[知识到工具研究](../research/2026-09-11-knowledge-to-tools/report.md)及[来源清单](../research/2026-09-11-knowledge-to-tools/sources.md)。研究仍按原核查日期使用，不因公开而视为重新验证。
