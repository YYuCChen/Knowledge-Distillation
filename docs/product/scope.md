# 当前产品范围

## 已公开的能力

知识蒸馏器是本地优先的个人阅读与知识工具。它将支持的材料处理成有来源依据的知识，对影响理解的识别疑点提供核对，发布来源型笔记到用户选择的 Obsidian Vault，并支持知识整理和回顾。

公开 V1.1 构建为 `2026.09.11.16`，提供 Apple Silicon macOS 与 Windows x64 包。系统要求和已验范围以当前 Release 与根 README 为准。有 Windows 包不代表公开源码中的每条开发命令都已在 Windows 验证。

输入包括抖音、小红书、知乎、微博、X、YouTube、B站已支持的素材类型，直接文本，以及单个 PDF、EPUB、UTF-8 Markdown 文件。平台接入不是支持该平台任意 URL 或内容形态；登录、权限、限流及内容可用性会导致明确失败。

飞书在用户配置后承接受支持的消息投递和核对交互，不是任意文件/音频的通用入口。电脑和本地应用需要运行。

用户浏览来源知识，使用普通本地搜索和 Topic 组织，主动触发实质整理。AI 新知保持独立标识；用户作出判断并追加想法。普通浏览/搜索不等于授权生成新知。

## 数据与发布

SQLite 保存应用正式记录。Obsidian 承接来源材料及来源型笔记；当前 AI 新知与个人判断保留在应用中，不自动发布为 Obsidian 笔记，不提供通用双向同步。

主要表面为投递/最近知识、主题/搜索、新知、设置。V1.1 设置已经包含版本更新；旧稿中“设置不承担升级”“Windows完全未发行”等说法不是当前范围。

## 明确限制

当前不是通用知识问答、跨设备自动同步或团队平台。不得从现有输入能力推导出整个目录/Vault递归导入、任意平台类型、任意附件、或自动代用户执行业务任务。

当前已取消的同题综合不能借未来持续研究方向被静默恢复。

现有公开源码快照与已发布二进制不保证逐字节对应，报告可复现性时必须保留这个限制。
