# Windows 差量更新后续优化：原始要求摘录

来源：产品规格 §14 中明确标记的 2026-09-11 远期优化条目，仅摘录这一条。它不阻断当时 V1.1 发行，也不代表优化已完成。约129 MB/40 MB 是当时记录的产物量级，不是所有后续发行的固定值。

- 2026-09-11 远期优化待办（不阻断本轮 V1.1）：Windows 当前差量为文件级策略，文件摘要变化即传输整个文件；因此小幅源码改动仍可能重复下载约 129 MB 的主程序和约 40 MB 的更新 helper，效果明显弱于 Mac 的块级二进制差分。后续应评估并落地适合 PyInstaller 冻结产物的块级／二进制差分，或调整冻结产物结构以隔离高频变化代码；不能只以“比完整包小”作为优化完成。验收须以连续两份真实 Windows 发行包验证：普通小修复不再整文件重传大型可执行文件，补丁签名与基线匹配有效，重建后逐文件摘要与目标完整包一致，并继续覆盖下载损坏、补丁不适用、重建中断、新版启动失败和旧版恢复；不得以缩小体积削弱现有数据／Vault 路径保护、显式完整包回退或更新真实性。
