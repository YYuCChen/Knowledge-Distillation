# 知识整理与知识生长决策台账

## 0. 文档定位

本台账记录 `KNOWLEDGE_ORGANIZATION_AND_GROWTH_PRODUCT_CONTRACT.md` 的产品裁决基线。

本台账与产品契约正式落库时，只表示产品裁决已经完成；“手动整理、知识关系生产、新知候选和已认可新知资产仍未实现”是当时的 decision-time 工程状态，不是 CURRENT 断言。M6 G1～G3 后续已经实现；CURRENT 只由真实 Git、代码／测试与 `PROJECT_CONTEXT.md` 证明。

2026-08-29 替代关系：`V1_INSIGHT_JUDGMENT_EVOLUTION_CONTRACT.md` 的 D2-IJE-01 已定向替代 ORG-042 的“Accepted 未来进入 Obsidian”部分。ORG-042 保留为历史决定；当前有效目标是 Insight 不进入 Markdown／Obsidian，pre-release accepted publication rows／files 是 disposable 测试产物，不迁移到正式版。来源型 `KnowledgeResult` 发布不受影响。2026-09-02 进一步收窄为 SQLite 保留全部正式历史，Local Web 对 Accepted 只投影 current，historical 无 Local Web／Obsidian 用户入口。

原则：

- 契约正文保存当前有效规则；
- 本台账保存决定、主要依据、直接后果与后续归属；
- 后来调整时，不静默覆盖旧决定，应记录替代关系；
- 本台账不定义 schema、API、模型、prompt 或工程实现。
