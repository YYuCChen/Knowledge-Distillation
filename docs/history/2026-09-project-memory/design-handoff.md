原记录的Presentation实点覆盖：更新说明展开/收起/已读保持、下载与忙碌禁用、分组收起、社媒两层帮助，以及首页→主题→设置→返回主题→新知。并非每条连线都实点，也不是后台端到端测试。

1440×1024代表页及640窄窗做过对照；四主页面代表窄窗不能代替所有状态与窗口组合。640豆包手填高897.8px，对照浏览器896.875px；Qwen高296px，对照294.578px，保留约1–2px文字取整差。原生滚动条占位不同不能直接当同环境像素误差。

浏览器代码字体为Menlo，当时Figma环境不可用，使用明确命名的可编辑Roboto Mono替代；不得称字形完全一致。原生tooltip、系统窗口、凭据、登录、下载/安装、实际保存与Obsidian跳转是宿主或服务边界，原型不伪装执行。

当时范围不含Windows、手机版、独立首次引导、第三方Obsidian阅读界面重建或业务代码修复。

## 维护依据

设计源文件仍需在原设计服务中维护；本公开文档不是原生设计文件备份。历史脚本是方法与增量证据，不能保证一键重建当前母版。新反馈或程序UI发生变化时，核对真实基线后定向同步，优先改源组件、变量和样式，再读回实例的文本、宽高和原型。

当时桌面设置分组638px、详细配置510px、更新内容574px；640原生滚动条样例主列578px、分组576px、普通详细区512px、更新内容542px。旧608px主列属于不同环境记录，不能机械混用或当永久规范。
