# 不完整 ASR 的局部恢复

识别器明确以 repetition、length 或其他非正常原因结束时，输出不能提交为完整来源。第一次不完整保留失败状态；重试仍不完整时，只细分失败音频段。优先选中部低能量间隙，不能把“没有全零采样”解释为没有停顿。无法找到低能量间隙时使用中部边界；这仍不保证所有语音的切分都没有识别误差。

子段精确覆盖原段全部 PCM 帧，不删除或重叠原音。送入解码器时在两端各补 250 ms 静音，以减少片段边缘识别丢词；静音不属于来源，返回时间轴减去补边并限制到原段范围。任一子段仍不完整，整体保持未完成；成功子段独立保存，后续重试只继续失败部分。正常结束、帧覆盖完整和转写准确分别判断，不能互相代替。

每个外层片段的一次恢复最多进行 16 次识别调用，已缓存成功子段不消耗调用预算；子段最短 1 秒，再短且仍不完整时保留失败。预算是单次工作上限，不是内容有效性规则。细分计划绑定原音身份及恢复算法版本，合并缓存与普通识别缓存分开，避免旧恢复算法的合并结果被直接接受。计划、子目录及解码临时文件拒绝链接写入。

Qwen 运行绑定额外纳入运行包/模型修订、Python 版本和解码工作脚本摘要。身份不明的旧 Qwen 临时识别缓存不能冒充当前运行身份；已提交的来源事实不因此被修改。工作目录继续遵循现有临时资料生命周期，正式知识和 Vault 不用于验证。

验收应同时检查自然重复停止的真实模型恢复、原媒体已知词序完整性、不同语音样本、原音与补边坐标、预算耗尽、只重试失败子段、重启复用和模型身份变化。生成媒体与受控故障要分别标明；样本通过不保证未来所有来源零错误。
