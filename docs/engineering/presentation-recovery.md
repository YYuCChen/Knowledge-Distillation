# 展示字段与局部恢复

三个互不相同、各四个汉字的扫描标签仍是现行设计。候选标签不合规时，只向模型请求标签字段，不替换候选判断、论证、前提、连接理由、参与者或谱系。完整原响应保留；每次最多请求四项候选的标签，每项最多 512 输出 token。已完成标签按完整候选身份复用，后续重试继续剩余字段。输入、模型或请求规则变化时不得复用旧候选。结构恢复成功仍须通过原有整体语义与事务校验，不等于候选已发布。

Topic 的成员归属与相对顺序由模型提出。排序值必须是互不重复的非负整数；从 1 开始或中间有空号时，程序按既定相对顺序构造连续成员序列。未知 Topic、重复归属、重复排序值以及漏写或多写成员仍拒绝，不补造成员或自动决定有歧义的顺序。

连接理由继续保留 1–3 项合同。不因超出数量而直接截掉理由，也不把必要论证移除来满足展示约束。

模型服务 HTTP 401 表示身份认证未通过；403 保留配置并提示访问权限；404 保留配置并提示端点或型号。合成响应回归覆盖两种 LLM HTTP 传输，不代表已对所有真实服务或历史适配器逐一验收。

来源型知识的标题、副标题和摘要中，普通文字换行只规范成空格；代码标记、制表符和代码缩进不自动改写。引用原文、观点和论证保持原样。若仅展示字段重复、缺失或不符合单行约定，先确认其余内容与证据可通过原校验，再单独请求这些字段；每次至多一次、1024 输出 token。原响应和未完成候选按来源、模型及请求身份保存，重试复用同一候选；恢复完成记录仍不是数据库提交证明。集合综合采用独立契约，本轮未新增其展示限制。

YouTube 字幕归属必须与返回清单中的轨道 URL 精确对应；重复归属或缺失 URL 不推定为人工字幕。翻译参数按 URL 解码后判断；来源语言缺失仍明确标为未核验，可选字幕故障保留音频后备路径。
