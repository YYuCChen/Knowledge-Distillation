# Manual card projection and reconciliation

Home reads persisted card enqueue_seq within the existing independent/collection scope, then appends failed tasks. A multi-member judgment group stays one card when only some members remain. It exposes the selected count, member positions, shared full context, and explicit single-member unable/recognition-reference actions. Old callbacks remain single-member operations.

Foreground reconciliation runs every two seconds, hidden pages every fifteen seconds; visibility/online events request an immediate read. Requests time out after five seconds and at most one status read is in flight. Playing audio and editing do not stop polling. A response started before a local action cannot overwrite the action response.

Keyed DOM reconciliation retains surviving input, details and audio nodes. Deleting preceding cards happens before matching so it does not detach a focused surviving control. The first surviving visible card anchors scrolling. Changed audio_revision offers a user-controlled switch rather than replacing the playing source. Shared context expansion keeps exact source marking and full callback values.

`tests/v1/browser/manual_browser.py --output PATH` runs actual agent-browser against a synthetic queue serving production home.js. It records twenty playing and twenty paused reconciliation samples, max/p95 commit-to-visible time, node identity, draft/focus/selection, anchor and audio time. This is browser integration evidence; it does not establish real group mutation timing, native IME, Feishu devices, or a frozen packaged application. These remain separate acceptance gates.
