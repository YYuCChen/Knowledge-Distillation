VBS 快捷方式通过原生 cscript 和 COM 读回检查；夹具仅把脚本所在目录及桌面输出改到隔离目录，未写正式桌面，重复创建被拒绝且已有快捷方式保持不变。

没有将仅构建成功、声明版本或导入成功当作 Qwen 识别已完成。实际旧 Mac 3.13、Windows 3.12 构建命令被版本门禁拒绝；旧解释器不能作为新组件的就绪依据。符合兼容 ABI 的 `abi3` 扩展不代表包含另一个 Python 解释器。

数值、下载地址与 SHA-256 以[运行环境契约](../../engineering/python-runtime.md)及其引用的唯一 JSON 配置为准。构建与组件解释器均采用 CPython 3.11.16；安装依赖、主程序和独立 helper 均已重新打包。保留 Qwen3-ASR 模型 ID 与固定修订；Mac 使用 MLX，Windows 使用 Transformers CPU 后端。SciPy 调整到支持 3.11 的 1.17.1；Windows Qwen 重新锁定 cp311/兼容 abi3 轮子。

## 生命周期与门禁

升级应用后，旧 Qwen 组件若不符合新契约，需要在设置中重新安装并启用。依赖契约变化时仅重建安装暂存区的 Python，保留该暂存区的模型下载进度。识别和安装共享锁；检查旧解释器在用状态，搬迁后再次实际识别，失败恢复旧目录。恢复旧目录不表示新应用允许调用不符合契约的旧解释器。

两平台都已用独立真实组件验证重装、重启识别、在用保护、搬迁后自检失败回退和旧目录退役。Windows 包含实际 3.12.10 旧组件到 3.11.16 的迁移。只有新环境验证成功后才删除已识别旧 Python 与下载缓存；未知或独有模型文件继续保留。正式应用数据、系统 Python、其他项目和受保护恢复原件不属于清理范围。

发行门禁要求两个平台的完整包、更新辅助程序、可选组件、旧版升级、失败回退、差量重建、签名、文件大小及线上资产分别有证据。最终矩阵区分通过、失败、未验证和不适用，不用测试总数补齐空项。

## 支持边界

macOS 14+、Apple Silicon；Windows 10 22H2 x64 实测。Windows 11 与 Windows ARM64 尚未验证，Intel Mac 不在支持范围。Mac 仍未公证，Windows 仍未作发行者代码签名；更新资产独立使用 Ed25519 签名。

Mac 原生自动更新测试使用独立 bundle ID、临时更新公钥的签名副本，避免操作正在运行的正式应用；生产差量另外逐项重建比较并验证严格代码签名。测试没有替换正式应用或使用正式 SQLite/Vault。旧 `2026.09.13.3` 的标签、资产和历史验收保留追溯，但其运行环境不一致，不能代替本次统一要求。F-10 Windows 块级/二进制差分仍未实现。
