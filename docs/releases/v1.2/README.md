## 证据及边界

公开测试全部为合成文本、音频和几何，不含真实任务转写、图片、Vault 或账号配置。现场报告只支持特定问题：未保留原 ASR 的历史任务不能声称逐字复现；Vision 独立调用与当时进程解码路径并非完全相同。本轮测试验证新代码行为，不能反推历史事实损坏。

文本校验不能证明任意语义等价，也不能证明自动字幕逐句准确。拒绝修改只表示没有采用模型提议，不表示基线经过人工确认。原语言缺失、来源绑定不完整或字幕无效时保守回退；分段 ASR 没有成功完成全部片段时不能建立完整来源事实。

诊断原输入、模型响应及分段音频位于任务自有临时目录，受现有清理规则管理：活动任务、失败但仍可恢复的任务及待确认任务保留；来源事实成立或明确放弃后按生命周期清理。72 小时不是删除活动恢复数据的授权。持久来源链仅保留必要基线、验收操作、字幕回链及规则诊断，不上传运行资料。

## 发行门槛

完整候选必须从干净提交构建，Mac 与 Windows 分别验证原生运行、冻结包、版本元数据及归档。完整包保留用于首装与失败恢复；差量必须从上一正式完整成品及本轮完整成品生成并签名，重建摘要须等于目标完整包。验证源码提交、构建号、签名、公钥、哈希、appcast、差量基线、失败回退及数据保护后，才请求最终公开发布决定。

尚未完成的原生、签名、差量及公开发布事项必须列为未验收，不能以逻辑回归或 ad-hoc 手动候选替代。不会安装或替换用户正式应用，不用正式数据验证迁移。
