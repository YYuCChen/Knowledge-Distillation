# V1.2 · 2026.09.14.1

本次修复来源复核与恢复链，并改用独立模型、固定平台基座和差量分发。发行标签直接对应已验收源码 `72f52d12b8bb5bb5ff516a052dfa3aabd899a348`。

## 安装与升级

- Mac Apple Silicon / macOS 14+：下载 `KnowledgeDistillerInstaller-macos-arm64.zip`，解压并打开安装器。Windows x64：下载 `KnowledgeDistillerInstaller-windows-x86_64.exe`。
- 新装使用安装器选择程序与数据目录，下载并核验必要资源后安装；无需系统Python。首次仍需下载约1.55GB（Mac）或1.85GB（Windows）的主程序和文档模型资源，实际大小以安装器显示为准，安装器与可选Qwen另计。
- V1.1、V1.2 .3、.9用户使用同一安装器完成一次性迁移，选择现有程序和原数据目录。已核验的旧文档模型会导入并复用。旧应用内更新器不自动桥接本协议，不向它提供虚假完整包地址。
- Mac尚未公证，Windows安装器未作发行者代码签名；Mac应用代码签名与组件发布清单签名已按各自范围核验。不要关闭系统整体安全防护。
- 离线安装需要对应签名清单及其全部匹配资产；仅下载源码压缩包不能安装。

## 此次变化

- 保存完整复核结果、疑点解决依据与用户决定版本；重试、重启和并发处理不会以省略疑点冒充解决。
- 从原文逐项应用有来源支持的局部修改，区分编辑被拒、实质疑点和技术失败。语法润色、相似度或模型自报不能单独授权改写。
- 区分文本完成与时间定位可用性。持续不完整的真实ASR采用有界细分、解码边缘补静音及已完成子段缓存；普通应用缓存绑定实际平台的Qwen运行包、模型与worker身份。Windows保留原始解码中的重复词句，对密集重复触发更短音频恢复；真实30词普通源码队列和最终冻结程序均恢复30/30，另有23词重复、36词短语重复及普通语音原音对照通过；CPU密集重复场景可能明显较慢，冻结程序30词场景含首次拒绝、恢复和重启约14分钟。
- 保留可用字幕/音频后备、逐图OCR进度与局部展示字段恢复，维护原有标签和论证约束。
- 文档模型和平台基座在固定非Latest资源发布中复用；每次业务更新发布直接差量与签名清单。Windows采用HDiffPatch文件内补丁，保留旧format 1读取；不再每版上传全量安装ZIP。
- 主程序、Qwen、更新辅助程序和安装器实际Python统一为CPython 3.11.16。
