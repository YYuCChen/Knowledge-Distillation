# V2.0 正式发行：raw 素材层、飞书随手记与 vault-kit

V2.0 于 2026-09-30 发布，macOS 正式构建为 `2026.09.30.4`，标签 `v2026.09.30.4` 直接对应构建源码 `ea0896a42b19e9b3fd464e78492a7bd535561869`。二期主体开发由 Claude Code 在 `phase2/foundation` 完成；账号中断后，Codex 在同一工作树核对会话、提交、候选包和正式数据状态，完成最后四项修复的复验、版本统一、正式安装、更新链、文档与发行收口。

本版只发布并验收 macOS arm64。Windows 没有进入二期开发、构建或验收，最后一个公开版本仍是 V1.3；V2.0 Release 中保留旧的 Windows V1.3 签名清单和更新源，只用于避免既有客户端的 Latest 地址失效，不代表 Windows V2.0。

## 交付内容

- 应用新增不可变 raw 素材层。外部材料、本人附言和本人自述分别记录，保留原文、来源、身份和取代关系；编号、路径和已写入字节受数据库约束保护。
- 飞书随手记支持文字、语音、链接和已接入附件。身份先按确定规则判断，需要时交给已配置的 Jev；拿不准的内容进入首页由用户判断。语音复用本地 ASR、疑点和订正链路。
- `vault-kit` 提供初始化、检查、raw 取号、批量摄入和关系图谱维护。Agent 只维护 wiki 与自动区，不修改 raw。
- 二期知识骨架补齐 Topic、关系、洞见、演化、重新审查、替代与 lineage 的持久化、约束和公开文档。
- V1.3 定稿疑点卡和一次判断同步保持不变；V2.0 没有借工程收尾改版既有 UI。

## 最后一轮修复

- 飞书多段长文字不再因为富文本结构中出现图片节点而把整条内容误判为图片。
- Apple Vision 对贴近图片边缘的合法文字框采用浮点容差；原失败 X 素材的 4 张真实图片通过回归。
- 点击 Dock 时若已有页面无法被浏览器聚焦，不再弹“未能显示已有页面”；仍按既定方案尽力唤醒，连续失败时另开一页。
- `vault-kit` 的调用说明和批处理进度改为面向中文使用者的清晰表述。
- 项目包版本和依赖锁统一为 `2.0.0`，不再残留 V1.3／0.1.0 元数据。

## 正式数据升级

安装前完整保留旧应用、Application Support 和 Vault 的可恢复副本。正式应用由 `2026.09.30.2` 升级到 `.4` 后：

- 数据库 `quick_check=ok`，schema 保持 21；核心表数量逐项与升级前一致。
- 正式 Vault 的 `kb.py run --dry-run` 为 0 错误、0 提醒，没有因替换应用改写 raw 或知识页。
- 本地服务首页、设置和洞见页面返回 200；飞书 worker 重新取得 token 并持续轮询。
- 已配置的 Vault、Jev、飞书和各平台凭据原样保留；发行与验收没有公开实际知识数据、密钥或浏览器资料。

真实现场验收已经覆盖文字身份判断、本人附言、语音转写、链接邻接和 raw 写入。安装 `.4` 后，用户再次发送长段多段文字，内容正常进入队列并最终完成，写入新的第三方 raw；原失败 X 任务点击重试后同样成功完成并写入 raw。用户从 Dock 点击应用时也不再看到“未能显示已有页面”。三项结果均由用户确认，任务和 raw 状态随后从正式数据库只读核对。

## 安装、升级与回退

- 新安装或较早版本：下载 `KnowledgeDistillerInstaller-2026.09.30.4-Mac-arm64.zip`，选择应用和数据目录。
- 公开 V1.3：可在应用设置中检查更新，直接使用签名差量升级。
- 手动恢复：完整包为 `KnowledgeDistiller-2026.09.30.4-Mac-arm64.zip`；全部公开资产哈希见 Release 的 `SHA256SUMS`。
- V2.0 数据库为 schema 21。应用回退和数据回退必须一起处理；不能直接用 V1.3 打开已经升级的数据。需要回退时，恢复安装前的应用、Application Support 和 Vault 三份备份。

## 已知边界

- 本版不承诺 Windows、Intel Mac、跨设备同步、团队协作或通用知识库问答。
- 本机签名证书未公证；首次打开仍按 README 的安全说明操作。
- 飞书机器人、Jev、云模型和内容平台依赖用户自己的连接、额度、账号状态与平台许可；本地优先不等于全离线。
- `BUG-20260917-01` 的真实现场根因仍缺证据，本版只补充诊断阶段码，没有猜测式修复。
