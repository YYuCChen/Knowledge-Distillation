# V2.0.1 · 2026.10.10.1

## 长篇确认性能修正（准备构建 2026.10.10.3）

用户升级到 2026.10.10.2 后仍报告确认卡迟迟没有完成。本机只读版本核对与进程采样确认正在运行该构建、主进程持续高 CPU；源码检查发现每次提交保存原音锚点时对原转写与当前稿执行全文 SequenceMatcher（autojunk=False）。先前 84 卡首页测试没有覆盖该提交路径，因此其速度提升不能代表确认动作已经解决。

修复对齐算法，以唯一上下文建立单调锚点，把精确比对限制在小段内，并限制缓存为两份文本组合；找不到可靠上下文时保留未定位，避免错误播放重复词。保留 UI、保存前的原音位置、判断版本检查与原子事务。独立合成中文 86,670 字、修改分布于全文：旧版计算超过 8 秒未结束（仅终止本任务创建的合成子进程），新版冷计算 0.119 秒，精确匹配覆盖 98.85%。这不是正式数据库的性能测量，也不代表所有未来素材耗时。

181 项相关回归通过，包括真实 POST 确认入口、连续不同长度替换、返回首页、重新读取数据库后的原音定位、并发与版本冲突、原音恢复及更新页面。长篇连续两次提交与返回首页的合成用例总耗时 0.59 秒。发行成品与公开更新入口尚待本构建完成后验收；本机应用仍由用户自行升级，未写入正式数据库或 Vault。

基于已恢复的 V2.0（2026.09.30.4），只发布 macOS arm64。

修复大量音频答疑卡的首页卡顿：单次请求复用素材确认记录和上下文索引，无过期内容时不争抢数据库写锁。前端连续提交按顺序发送，保留各卡点击时的答案，失败恢复输入和原按钮状态；折叠卡的音频在展开时才加载。沿用现有界面、按钮文案和音频版本切换规则。

独立合成 84 卡首页耗时由 3.760 秒降至 0.393 秒；这不是用户正式数据的性能测量。签名成品、直达升级差量和公开入口验收均已通过。本机安装由用户通过应用内升级自行完成，发布过程不替换本机应用、不处理用户疑点或重跑正式任务。

Windows 保留最后正式 V1.3 的清单和更新入口。现有文档模型及平台基座复用，私人内容和凭据不进入发行资产。

## 更新入口修正构建：2026.10.10.2

用户在旧 V2.0 检查新版后发现按钮不恢复，刷新后出现 JSON 解析错误。根因是组件更新 DTO 没有传统完整包字段，updates.js 却在渲染隐藏的完整包备用按钮时无条件访问 release.full.size，导致下载按钮尚未设置 action；后续点击发往 undefined 路径，404 空响应触发原始英文异常。

修正仅在确有完整包字段时读取其大小，保留原按钮及文案；未初始化的按钮回到检查动作，无效 JSON 响应使用原状态区反馈。独立 WebKit 回归覆盖首次检查、刷新已有可用更新、下载及进入安装中；原代码两项失败，修复后相关更新回归 24 项通过。已安装旧版无法依靠损坏的入口接收该修复，首次需使用修正构建的安装器选择原应用及原数据位置；本机仍由用户自行安装。

修正构建已正式发布为 [Latest 2026.10.10.2](https://github.com/YYuCChen/Knowledge-Distillation/releases/tag/v2026.10.10.2)，非草稿、非预发布。源码标签直接对应 `d56a3dfdd83a7f655c28c14ce9580b7afad4b7b1`；PR #21 合并提交 `a6875b38316de1bc17ce81e20b186a4a5f1f2f50`。GitHub quick 和 Windows 源码回归通过。
