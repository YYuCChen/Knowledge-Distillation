## 本次修复

- 修复组件更新快照未提供 `full` 时，更新页初始化读取 `release.full.size` 抛错的问题。原异常发生在按钮 action 设置与轮询建立之前，使点击仍显示“检查更新”的按钮实际请求 `/settings/updates/undefined`；其空 HTML 404 响应又被强行解析 JSON，最终显示 `Unexpected end of JSON input`。这不是此次已证实的 token 失效。
- 对可选 `full` 做存在性检查，让组件更新正常设置下载 action 与轮询；非 JSON／空错误响应沿用既有“操作未完成，请重试。”，避免以 JSON 解析异常覆盖操作错误。原完整包回退仍须用户明确选择，同源与 token 门禁保持。

两处具体差异已获用户批准。本补丁保留 V3.0 的 raw → wiki、Schema 27 与数据边界，不重跑真实资料、不改变历史用户判断，也不自行安装或重启用户正式应用。

## 升级方式

受此缺陷影响的 V2.0／V3.0 更新页无法完成按钮流程。本次请下载独立安装器，由用户自行升级；不要求通过旧应用的更新按钮完成安装。既有后端 HTTP 更新验收不代表旧更新页可用。升级前同时备份应用数据与 Vault，正常退出旧应用，选择原程序与数据目录；不并行运行两个版本。
