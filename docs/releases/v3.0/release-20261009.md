## 核心变化

- **素材先留存，知识统一整理**：新投递先保存完整来源及其身份，再由「开始整理」进入 Wiki typed 任务；原文、来源支持、AI 推断与用户判断保持分离，不再沿旧 SQL derive 为新素材生成知识。
- **完整上下文与可恢复任务**：按冻结来源和关联组分批，保留全文、稳定编号与来源定位；生成、独立核对、体检、支持检查、发布读回分别留存记录。正常无知识可以结束，未知或检查失败不能冒充成功；恢复沿原任务保留预算与已完成批次。
- **逐主张核对依据**：Wiki 候选检查引用范围、归属、否定、数值和条件；保留有知识价值的人物／作品与概念关系，禁止凭外部常识补出处。程序管理事实与原文证据分开核验，通过支持检查仍需发布读回才能接受。
- **来源与投递边界**：接入通用网页正文及原附件留存、多链接独立收件与范围处理。来源不完整、不可访问或有歧义时保留实际状态，不承诺任意网页可用或采集全量。
- **随手记身份判断**：作者身份与附言对象分别判断，使用有限的稳定候选及已有标题／摘要；不按文本长度猜第三方，歧义待确认，用户明确判断优先。active 决策客户端保留 Jev／Clef 各自概率语义，合成接口通过不等于真实模型判断质量已验。
- **界面与数据兼容**：按已展示并批准的候选接入本轮界面调整；数据库使用 Schema 27，保留既有来源、用户判断和历史任务，不以升级自动采纳旧 unknown 或重分类历史素材。

## 本版范围

- 仅面向 **macOS Apple Silicon（macOS 14+）**。不提供本轮 Windows／Intel Mac V3.0 构建；已有 Windows 发行不据此升级为 V3.0。
- **R11 Reddit 与 R12 pyannote 已获同意延期**，不列为本版交付能力。Reddit 的内部授权／导出及删除合同不代表在线采集已上线；pyannote 的内部适配与对齐合同不代表说话人分离已部署。现有 Qwen／豆包转写路径继续保留。
- 不宣称未验证的 R02 协议跳转、真实 Jev 模型能力、真实声学效果或所有来源类型均已验收。

## 从 V2.0 升级

拟沿现有签名更新入口提供 V2.0 → V3.0 自动升级；下载清单、产物和实际升级结果须完成下方验证后才可发布。用户在原应用内更新，不需另建数据库或 Vault；本发布准备不安装或重启用户正式应用。

升级前同时备份应用数据与 Vault，避免两个版本并行运行。Schema 27 升级后不可用 V2.0 直接打开新库；回退应恢复升级前备份。

升级不自动重跑真实素材、重新识别历史音频、重建历史知识或覆盖人工笔记。后续整理由用户按现有入口发起，处理范围以任务冻结与实际状态为准；可选模型不因本次升级自动启动或下载。
