# Bundled Home fonts

The application bundles the variable Noto Sans SC and Noto Serif SC faces used by the approved Figma Home frames. Runtime pages must not depend on a network font service or silently substitute a macOS system font.

- Upstream: `google/fonts`
- Pinned revision: `5e35378e6bda803962ee6fd257e444a7d459660d`
- Sources: `ofl/notosanssc/NotoSansSC[wght].ttf` and `ofl/notoserifsc/NotoSerifSC[wght].ttf`
- Web conversion: FontTools WOFF2, with no glyph subsetting
- Noto Sans SC WOFF2 SHA-256: `02278c39cc4b77cddfcebbded842f7f93c822e11f58bde4eab2c3bfa363c93c1`
- Noto Serif SC WOFF2 SHA-256: `a29913d298be5c4bccc0aaddc1de965e1a33333e24903f6336d8c2b5b0cb3f4d`

Each font's SIL Open Font License is stored beside the corresponding WOFF2 file.
