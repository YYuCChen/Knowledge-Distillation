知识蒸馏器 · Mac 文件包

支持范围
macOS 14.0 及以上；Apple Silicon（M 系列、arm64）。本次实测：macOS 14.6。
此文件包不支持 Intel Mac、Windows 或 Linux。尚未在另一台干净 Mac 上验收。

开始使用
1. 解压 ZIP，把整个文件夹放在你希望长期保留的位置。
2. 双击文件夹内的“知识蒸馏器.app”。它会启动本机服务，并自动用默认浏览器打开页面。
3. 在设置页选择 Obsidian Vault，按需配置语言模型和语音识别。选择目录后请查看仓库状态；如提示尚未识别，在 Obsidian 选择“打开文件夹作为仓库”，选择同一个目录，再回应用重新检查。笔记已保存但暂时不能跳转时，可在首页点击“在 Finder 中显示笔记”。
无需安装 Python、Node、FFmpeg、Git 或 pip，无需手动输入命令或设置端口。
可以直接从解压目录运行；也可以将整个 .app 移到“应用程序”。请勿拆开 .app 内部文件。

首次放行
此包采用 ad-hoc 本地签名，没有 Developer ID 签名或苹果公证，不需要苹果开发者账号。
第一次双击后若提示无法验证开发者或无法检查恶意软件：
打开“系统设置 → 隐私与安全性”，找到刚被拦截的知识蒸馏器，点击“仍要打开”，再确认“打开”。
完成后通常无需再次放行。具体文案随 macOS 版本不同。
只为你确认来源的本文件包放行，不必关闭系统整体安全保护。
苹果官方说明：https://support.apple.com/zh-cn/102445
如果设备受组织管理而禁止放行，此文件包不能绕过管理员策略。

随包提供与按需配置
基础包包含 Python、Node、FFmpeg/ffprobe、OpenCLI、Apple Vision 桥接以及完整 Docling 文档运行库（含表格、公式和扫描件处理依赖）。
Mac 图片识别使用系统 Apple Vision，不安装 PaddleOCR。
Docling 所需的版面、表格、公式及扫描件 OCR 模型权重、分词器和字典均随基础包提供。PDF/EPUB 文档解析首次使用无需下载模型，可离线处理本地文件。
本地 Qwen 不在基础包中。在“设置 → ASR”点击“下载并安装 Qwen”，等到完成，再点击“保存并启用”。下载需网络与数 GB 空间；安装不会更改当前启用方案。
豆包语音识别和兼容 API 方案需自行配置有效凭据；服务商可能收费。
语言模型可使用本机已有 Codex 订阅配置或兼容 API。Codex、浏览器及第三方账号不随本包分发。
浏览器来源采集需要另有 Google Chrome 和相应网站登录；小红书和知乎还需在同一 Chrome 个人资料中安装并启用 OpenCLI Browser Bridge 扩展。应用自动启动包内连接组件，无需另装 OpenCLI 命令行；扩展显示 Reconnect 时点击重连，然后重新配置登录。普通页面使用默认浏览器即可。

退出与数据
关闭浏览器页面不会停止服务。需停止时，在 Mac 的“知识蒸馏器”应用菜单选择退出（或激活应用后按 Command-Q）。
再次打开 .app 会唤起页面。
数据和配置保存在：~/Library/Application Support/Knowledge Distiller
账号凭据由 macOS 钥匙串保存；Obsidian 文件仍在你选择的 Vault。
更新时先退出旧版，再替换 .app，保留上述数据目录和 Vault。不要同时从两个版本处理同一份数据。
本文件包不包含制作者的数据库、模型缓存、凭据或浏览器登录资料。

飞书投递
在“设置 → 路径选择 → 飞书机器人”配置自己新建的专用应用。
在飞书开放平台启用机器人能力，开通读取私聊消息、读取消息历史、以机器人发送消息和消息资源权限；事件与回调采用长连接，订阅 im.message.receive_v1 和 card.action.trigger，并发布到自己的可用范围。
填写 App ID / App Secret，验证后向机器人私聊发送本机显示的绑定口令。口令10分钟有效；绑定消息本身不产生知识。已绑定后可留空密钥重新连接，凭据仅保存在钥匙串。
仅接收绑定私聊的文本和链接。正常待办可在电脑或飞书核对，所需短音频/裁图会上传给当前机器人；知识仍保存在电脑与 Obsidian。电脑运行时才处理卡片操作，上线后自动补收。
若旧卡片过期或被删除、无法更新，在同一设置入口重新发送回执；已有任务不会重复创建。

阅读与媒体
新版笔记保留文本与来源链接，不再自动附带平台视频/图片。可在路径选择中启用可关闭的 Obsidian 阅读样式。
新完成且不再被其他任务使用的平台过程媒体自动释放；待确认与可重试任务保留需要的材料。升级前历史媒体有保护，不会自动清除。
