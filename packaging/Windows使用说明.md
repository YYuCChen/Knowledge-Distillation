# 知识蒸馏器 Windows

1. 把 ZIP **全部解压**到一个文件夹，不要在压缩包内运行。
2. 双击 `KnowledgeDistiller.exe`。浏览器会打开本地页面；服务窗口保留在桌面。
3. 进入“设置”，选择 Obsidian Vault，并配置自己的语言模型、语音识别与平台连接。
4. 使用首页投递文本、文件或支持的平台内容；在主题页回找，在新知页判断整理结果。
5. 关闭服务窗口或点击“退出知识蒸馏器”即可停止服务。关闭浏览器标签不会停止服务；再次双击程序可打开已有服务。

需要桌面入口时，双击同目录的“创建桌面快捷方式.vbs”；已有同名快捷方式不会被覆盖。程序、服务窗口和快捷方式统一使用原产品图标。

程序只监听 `127.0.0.1`，端口自动分配。基础包自带 Python 运行依赖、Node、FFmpeg、Paddle OCR、Docling 文档模型；无需安装 Python、pip、Node 或开发工具，首次解析文档不下载模型。基础包不含个人数据库、密钥或浏览器登录资料。

Qwen 为设置页选装组件。选择 Qwen 后点击下载并安装，失败时可明确继续；安装完整后仍需点击“保存并启用”。当前 Windows 组件使用 CPU 运行官方 Qwen3-ASR-1.7B，安装需要网络和额外磁盘；安装后可离线识别。安装不会替换已有 ASR 配置。速度与内存占用依机器而异，具体实测见同包测试说明。

Google Chrome、Codex、Obsidian 与账号不包含在包内。需要的平台功能应先安装 Chrome 并在应用建立的独立资料中登录；知乎需要日常 Chrome 的 OpenCLI 扩展。采用 Codex 通道时需安装并登录自己的 Codex。API 通道使用用户自己的服务配置，按服务商规则计费；交付测试未调用按量 API。

## 数据、更新与诊断

数据存放在 `%LOCALAPPDATA%\Knowledge Distiller`，与程序目录分离。设置中的版本更新会检查签名更新源，优先下载适用于当前完整版本的差量包；安装时自动退出后台进程、替换程序并重新启动，启动失败会恢复旧版。差量基线不匹配时明确提示，确认后可下载完整包。保留数据目录与自己的 Vault，不要同时用两个不同版本操作同一数据目录。

旧版尚无应用内更新功能时，退出后解压本版到新文件夹并启动，完成一次迁移。后续发行需为当前版本提供差量包；修改程序目录中的文件可能导致差量基线校验不通过。程序和数据目录须有当前用户写入权限。

安装意外中断后，再次启动会先恢复未验收的更新。如果恰好中断于程序目录切换且原快捷方式找不到程序，双击程序目录同级的“恢复更新.cmd”即可恢复旧版。该入口仅在更新期间保留，并会先确认没有运行中的应用；保留同级回退目录和数据目录内的 updates 文件以便恢复。

凭据由 Windows 当前用户 DPAPI 加密保存，不以明文写入配置；复制凭据文件到另一用户或另一台机器不能代替重新配置。

日志位于数据目录的 `application.log`。程序未购买代码签名证书；实际安全拦截及验证范围见测试说明。若组织安全策略阻止运行，应由设备管理员处理，不关闭系统防护。

历史候选曾在 Windows 10 22H2 x64 环境验证；本次源码归并的验证范围以 PR 记录为准，不能据此宣称 Windows 11、ARM 或干净虚拟机验证已完成。不要把开发机去除 PATH 的验证等同为干净系统验证。

原文件副本和 SQLite 是应用数据；Obsidian 发布不会覆盖已有笔记。变更 Vault 只影响未来发布，不搬移旧文件。
