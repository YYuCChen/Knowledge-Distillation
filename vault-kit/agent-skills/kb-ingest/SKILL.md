# 处理新素材

1. 先完整读一遍知识库根目录的 `AGENTS.md`（尤其第 0、2.1、7.2、7.3、8.3 节），本技能只是它的操作清单。
2. 运行 `python3 tools/kb.py`，读 `.graph/检查结果.md` 的"待处理素材"。每份都列了身份、渠道和标题。
3. 一次处理不超过 5 份，先外部后自述。每份素材都完整读入原文件（信封和全文），不截断。
4. **外部素材（身份：第三方）**，按 7.2：
   - 建来源页，`原始文件` 写 raw 路径；核心论点写成"作者认为……"，每条后附段落出处 `raw/…/编号.md#^source-N`。
   - 更新或新建概念页，同名异义用括注区分。
   - 与用户已有方法、认知的冲突只以候选方式写入。
   - 外部素材永远不直接生成认知页。
5. **自述（身份：本人 / 本人附言）**，按 7.3：
   - 判断是想法、反馈，还是都不是；本人附言挂到附言对象对应的来源页。
   - 用信封里的 `邻接` 按 8.3 找触发源，写成候选链接。
   - 认知页、方法页、实践记录一律 `确认: 候选`。
6. 写完在 `wiki/log.md` 追加一条 `ingest` 记录，列出处理了哪些 raw 路径（跳过的也写，并注明原因）。
7. 运行 `python3 tools/kb.py`。有"错误"就修，直到错误为 0；"提醒"能修的修。
8. 向用户简短汇报：处理了几份、新建和更新了哪些页、新增几条待确认（见 `wiki/待确认.md`）。最多顺带问一个问题（7.7）。

不要修改 `raw/` 下任何已有文件；不要手写带"（自动）"的小节、`index.md` 或 `待确认.md`。
