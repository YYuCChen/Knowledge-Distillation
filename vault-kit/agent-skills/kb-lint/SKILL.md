# 体检

1. 先完整读一遍 `AGENTS.md`（尤其第 7.5、7.6、9.3 节）。
   - 自动触发时严格遵守 7.6 的时机；用户明确要求立即体检时，以用户本次要求为准。
2. 运行 `python3 tools/kb.py`。有"错误"先修，直到错误为 0。
3. 以 `.graph/检查结果.md` 为基础，按 7.6 做脚本做不到的判断：
   - **矛盾**：每条都附双方原文。引用必须能在对应页面里逐字找到，找不到的一律丢弃。需要用户判断的，以候选方式写入。
   - **过时**：AI、投资主题中有效期超过 3 个月的事实，重新核对。
   - **下透**：悬空认知只列出，不催促；另列未实践的方法、长期不用的技能、被推翻未修正的方法。
   - **盲区**：只有外部观点的概念，以及从未被查询读取的页面。
   - **素材**：`待处理素材`的数量，以及引用了已被取代的旧素材的地方（改为引用最新文件）。
4. 重写各主题页的"概览"小节（其余小节由脚本生成）。
5. 按 9.3 的格式写 `wiki/体检报告.md`，在 `wiki/log.md` 追加一条 `lint` 记录。
6. 再运行一次 `python3 tools/kb.py`，确认错误为 0，并把报告要点告诉用户。
