# 陪读

1. 先完整读一遍 `AGENTS.md`（尤其第 2.1、7.2、7.3、7.10 节）。
2. 确认要读的素材：用户给出的 raw 路径，或 `python3 tools/kb.py` 检查结果里"待处理素材"中用户点名的一份。完整读入全文。
3. 按段落和用户讨论要点，引用时写段落编号，如 `#^source-3`。区分作者的观点和用户的看法，不替用户下结论。
4. 讨论结束后按 7.2 写来源页、概念页，与已有认知、方法的冲突只以候选方式写入。
5. 讨论中用户本人的发言，按 7.3 的"AI 对话中的发言"新建一份 `raw/自述/` 文件：
   - 先 `python3 tools/kb.py raw-id` 取号，只新建，不改已有文件；
   - 只写用户本人的话，按轮次分段。
   然后按 7.3 处理这份片段，想法一律以候选提出。
6. 在 `wiki/log.md` 追加记录，运行 `python3 tools/kb.py`，确认错误为 0。
